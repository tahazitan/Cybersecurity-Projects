# TAHA CYBER AWARENESS

Be Safe in Cyberspace. An independent Moroccan cybersecurity-awareness blog from Chefchaouen.

This folder contains a portable static version of the publicly published Darija blog, including **six complete Darija articles**, homepage, category search, About page, mobile navigation and sharing.

## Hosting
- **Cloudflare Pages:** connect the GitHub branch and set output directory to `TAHA-CYBER-AWARENESS`, with no build command.
- **GitHub Pages:** deploy `TAHA-CYBER-AWARENESS` as a static artifact from GitHub Actions.

All links use hash routing (`#/articles/slug`), so article links do not produce 404 errors on static hosts.

## Provenance
Text was copied from the published Darija articles at https://tahacyber.base44.app/. The logo, favicon and stylesheet are original app assets. This is a static portable implementation, not the original Base44 React source. French and English article translations from the source app are not included here.
